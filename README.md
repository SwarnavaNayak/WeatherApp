🌦️ Weather App with Dynamic Background

A responsive React application that fetches real-time weather data from OpenWeather API and displays a dynamic background image from **Pexels** based on the current weather condition.

---

 📸 Live Preview

> https://weather-app-tau-opal.vercel.app/

---

🛠️ Features

- 🔍 Search weather by city name
- 📸 Dynamic background image based on weather condition (e.g., Rain, Clear, Snow)
- 🌡️ Temperature display in Celsius
- 🌬️ Wind speed and 💧 humidity display
- 📍 Location with country info
- ❌ Error handling for invalid cities
- 📱 Fully responsive design
- 🎨 Clean and modern UI using React Icons and CSS
